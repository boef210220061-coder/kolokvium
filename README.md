# Сдай коллоквиум

Учебная игра по трудовому праву: 27 вопросов в четырёх темах, тесты, случайные карточки и карточки по порядку для каждой темы, конспект и тёмная тема.

Откройте `index.html` в браузере. Прогресс сохраняется на устройстве.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
